# Publication Boundary

This repository is the public artifact layer for the Mac Studio Local AI Workbench project.

## Include

- architecture notes
- setup summaries
- restore and verification scripts
- benchmark prompts and summaries
- model inventory names and approximate roles
- update policy templates
- RAG roadmap templates
- generalized example paths

## Keep private

- downloaded model files
- local cache contents
- private workspace links
- raw connector configuration
- local-only archives
- employer-specific or non-public material

## Path convention

Use generalized examples such as:

```text
/Volumes/<external-ai-volume>/07_Local_LLMs/ollama/models
```

instead of workstation-specific paths when the exact path is not needed.

## Scope

This is a personal infrastructure case study and reference build. It is not a hosted service, enterprise platform, or production system.
